# Date Interval

[Repository overview](../README.md)

Subtract two stored dates using separate day, month, and year fields.

## Implementations

The examples use different stored date pairs. Both use a simplified 30-day month when borrowing; this is not a full calendar-duration algorithm with real month lengths or leap years.

| --- | --- | --- |
