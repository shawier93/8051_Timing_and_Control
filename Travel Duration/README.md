# Travel Duration

[Repository overview](../README.md)

Subtract departure time from arrival time and format the elapsed hours and minutes.

## Implementations

The calculation handles minute borrowing; the implementation does not account for dates or overnight travel.

| Implementation | Input | Output |
| --- | --- | --- |
| [Keypad Hour Minute Difference](Keypad%20Hour%20Minute%20Difference/README.md) | Keypad | LCD and internal result bytes |
