# 8051 Timing and Control

[Back to portfolio](https://github.com/shawier93/Projects-using-Assembly-for-8051)

Compare dates and times, count events, and sequence output signals.

## Applications

| Application | Description |
| --- | --- |
| [Date Interval](Date%20Interval/README.md) | Subtract two stored dates using separate day, month, and year fields. |
| [Travel Duration](Travel%20Duration/README.md) | Subtract departure time from arrival time and format the elapsed hours and minutes. |
| [Traffic Light Sequencer](Traffic%20Light%20Sequencer/README.md) | Repeatedly send a sequence of signal patterns to three output ports. |
| [External Pulse Counter](External%20Pulse%20Counter/README.md) | Count external pulses and display the count when the display event is detected. |
